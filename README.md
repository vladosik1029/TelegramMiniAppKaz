# 🎰 Telegram MiniApp «Казино» — карточные игры против бота

Telegram MiniApp с карточными мини-играми **Blackjack**, **Очко** (русская «21») и
**пятикарточным дро-покером**. Все игры — против встроенного крупье-бота (дилер-бот
живёт на сервере), есть личный кабинет с балансом и админ-панель для управления
балансами всех игроков.

Виртуальные фишки, никаких реальных денег.

```

├── client/               # React (Vite) — интерфейс MiniApp
│   └── src/
│       ├── App.jsx       # главный экран, навигация (Игры / Кошелёк / Админ)
│       ├── api.js        # клиент API (шлёт Telegram initData)
│       ├── components/   # карты, рулетка ставки, кошелёк, админ-панель
│       └── games/        # Blackjack.jsx, Ochko.jsx, Poker.jsx
├── server/               # Node.js (Express) — API и вся игровая логика
│   └── src/
│       ├── index.js      # точка входа (API + раздача собранного клиента)
│       ├── routes.js     # роуты: профиль, игры, админ
│       ├── db.js         # SQLite (встроенный node:sqlite) — юзеры, сессии, история
│       ├── telegram.js   # проверка подписи Telegram initData (HMAC)
│       ├── bot.js        # скрипт привязки MiniApp к боту
│       ├── cards.js      # колода, суммы рук
│       └── games/        # blackjack.js, ochko.js, poker.js (логика на сервере!)
├── .env.example
└── package.json          # вспомогательные npm-скрипты
```

**Важно:** вся игровая логика (колода, ходы бота, выплаты) выполняется на **сервере** —
клиент получает только «вид» игры, читерить из консоли нельзя. Требуется **Node.js 24+**
(используется встроенный `node:sqlite`).

## Быстрый старт (локальная разработка)

1. **Установить зависимости:**

   ```bash
   npm run install:all
   ```
   > В PowerShell `npm` может быть заблокирован политикой запуска — используй
   > `npm.cmd` либо `cmd /c npm run install:all`.

2. **Скопировать `.env.example` → `server/.env` и заполнить** (см. ниже).

3. **Запустить сервер** (терминал 1):

   ```bash
   npm run dev:server        # API на http://localhost:3000
   ```

4. **Запустить клиент** (терминал 2):

   ```bash
   npm run dev:client        # UI на http://localhost:5173 (проксирует /api на :3000)
   ```

5. Открыть в браузере **http://localhost:5173**. В `DEV_MODE` браузер работает как
   тестовый игрок (`DEV_USER_ID`), Telegram не нужен.

6. Готовые проверки (по желанию):
   ```bash
   cd server
   node src/smoke.js        # симуляции тысяч раундов + статистика баланса игр
   node test/test.js        # E2E-тесты API (сервер должен быть запущен)
   ```

| `WEBAPP_URL`   | HTTPS-адрес MiniApp | см. деплой ниже |
| `PORT`         | порт API | 3000 |

## Деплой и подключение бота

Telegram MiniApp **требует HTTPS**. Простой путь для теста/продакшена:

1. **Собрать клиент:**
   ```bash
   npm run build:client          # соберёт client/dist
   ```
2. **Запустить сервер** на любой машине/хостинге (`npm start` в папке `server`) —
   он сам отдаёт и API, и клиент на одном порту.
3. **HTTPS.** Варианты:
   - быстрый туннель для проверки: `cloudflared tunnel --url http://localhost:3000`
     или `ngrok http 3000`;
   - постоянный: VPS + Nginx с Let's Encrypt (server_name → proxy_pass http://127.0.0.1:3000).
4. **Вписать полученный HTTPS-URL в `WEBAPP_URL`** в `server/.env` и перезапустить сервер.
5. **Привязать к боту:**
   ```bash
   npm run setup:bot
   ```
   Скрипт ставит кнопку меню «🎰 Казино» (web_app) и команду `/start`.
   Пользователь открывает бота → жмёт кнопку → MiniApp запускается под его Telegram-аккаунтом.
6. **Стать админом:** свой Telegram ID в `ADMIN_IDS` (до запуска). Твой аккаунт получит
   вкладку «👑 Админ» — установка/начисление/списание фишек любому игроку, включая себя.

## Правила и выплаты

### Blackjack (классический, S17)
- Дилер добирает до 17 и стоит; BlackJack с двух карт платит **3:2**; ничья — возврат.
- Есть **double**: вторая ставка списывается с баланса, одна карта, добор запрещён.

### Очко (русская «21»)
- Туз = 11 (смягчается до 1 при переборе), К/Д/В/10 = 10, цель — не перебрать 21.
- **«Пан-пан»** — обе раздачные карты пиковые (♠): мгновенная победа, выплата **3:1**.
- **«Очко»** — ровно 21 с двух карт: мгновенная победа, выплата **2:1**.
- Если оба собрали одинаковый «специаль» — ничья; пан-пан дилера сильнее очка игрока.
- Крупье добирает меньше 17.

### Покер (пятикарточный дро)
- По 5 карт; игрок меняет любые (0–5), бот сбрасывает слабое; сравнение комбинаций.
- Выплата при победе (×ставка): пара/старшая — **2**, две пары — **3**, сет — **4**,
  стрит — **5**, флеш — **6**, фулл-хаус — **9**, каре — **25**, стрит-флеш — **50**.
- Таблицу `PAY` можно править в `server/src/games/poker.js` (симуляции: `node src/smoke.js`).

## API (для справки)

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/api/init` | профиль: баланс, история; авторизация через `Authorization: tma <initData>` |
| POST | `/api/games/:game/start` | `{bet}` — начало раунда (blackjack/ochko/poker) |
| POST | `/api/games/:game/action` | ход: blackjack `hit/stand/double`, ochko `hit/stop`, poker `{discard:[0..4]}` |
| GET/POST | `/api/admin/users`, `/api/admin/balance` | админ: список игроков, `{userId, mode: set/add/sub, amount}` |

Защита: подпись initData (HMAC-SHA256 по токену бота), свежесть ≤ 24 ч,
ставка проверяется на сервере, балансы меняются в SQL-транзакциях, минус невозможен.

## Изменил баланс / тестируешь сам

- Админка внутри приложения: вкладка **👑 Админ** → тап по игроку → «Установить / Начислить / Списать».
- База SQLite: `server/casino.db` (можно снести — создастся заново со стартовыми балансами).
